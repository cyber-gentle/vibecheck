# VibeCheck AI Requirements

## Project Overview
An AI-powered CLI application for analysing
festival reviews.

## Technology Stack
- Python
- Google Gemini API
- JSON/CSV
- Git and GitHub

## Functional Requirements
1. Import reviews.
2. Validate review data.
3. Classify reviews using Gemini.
4. Generate statistical reports.
5. Answer questions using review evidence.
6. Export reports.
